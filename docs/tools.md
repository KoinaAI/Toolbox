# 工具行为

文本输入默认留空，配置项提供常用默认值；结果由实际输入计算或生成。站点不存储工具内容；收藏和最近访问仅记录工具 ID。

| 工作区 | 处理方式与范围 |
| --- | --- |
| Base 编码 | Base64/32/16 为常用选项；展开更多可选 36/45/58/62/85/91。UTF-8 文本，Base64 可用 URL-safe。36/62 使用页面注明的字符表与大端整数表示；58 使用 Bitcoin 字符表；85 为 Ascii85，91 为 Joachim Henke basE91。保留前导零字节。 |
| 身份证校验 | 18 位居民身份证的结构、日期、顺序码与 MOD 11-2 校验。解析信息默认关闭；地址码来自 @vant/area-data 2.2.0，历史区划可能未收录，且不等同实际出生地。不核验身份真实性。 |
| 颜色转换 | HEX、RGB、HSL、HWB、标准 D50 Lab、OKLCH，支持透明度和预览。超出 sRGB 时提示裁剪。 |
| 时间戳 | 秒/毫秒，支持小数和负时间戳；UTC 与所选 IANA 时区。 |
| 进制转换 | 2–36 进制正负整数，BigInt 保真，不接受小数与 0x 前缀。 |
| JWT | 解码 Header/Payload，查看未验证的签名与时间声明；不进行签名验证或权限判断。 |
| 字数统计 | 汉字逐字、英文与其他文字按 Intl.Segmenter 分词，混合累加；可选计入标点。另列字符、数字词、行、段落与 UTF-8 字节。 |
| Base64 转图片 | 本地解码 PNG/JPEG/GIF/WebP/BMP，预览和下载；拒绝 SVG/HTML。 |
| HTTP 状态码 | IANA 注册表快照，按代码、名称、中文含义及类别过滤。 |
| 日期计算器 | 日历日间隔、可选包含起止日，以及天/周/月/年加减；月底采用目标月最后一天。 |
| 时区转换 | IANA 时区与 DST；重复/不存在的时间默认报错，可显式选较早/较晚。 |
| Cron | 5 或 6 字段，中文描述及所选时区接下来十次执行时间；只预览，不调度。 |
| 单位换算 | 长度、质量、温度、面积、体积、速度、时间、数据大小、压力、能量。 |
| 随机数 | Web Crypto 拒绝采样，支持正负整数、定精度小数、批量与不重复。 |
| 密码 | 安全随机与洗牌，可选字符类别、排除易混淆字符；保证包含每类选中字符。 |
| UUID | 使用安全随机源生成 v4 或 v7，支持批量及大写显示。 |
| JSON 格式化 | 本地 Monaco，严格 JSON 验证、格式化与压缩，保留大整数字面量。 |
| SQL 格式化 | 本地 Monaco，标准 SQL/PostgreSQL/MySQL/SQLite/T-SQL/PLSQL，不执行 SQL。 |
| 正则 | JavaScript 引擎，匹配、捕获组、位置与语法说明；独立 Worker 超时终止。 |
| 图片压缩/转换/缩放 | 服务器 FFmpeg，输出 JPEG/PNG/WebP/AVIF，等比边界框或指定尺寸；JPEG 透明背景合成白色。只处理首帧、移除元数据，临时文件随后删除。 |
| DNS | 服务器解析器查询 A/AAAA/CNAME/MX/NS/TXT/PTR；不虚构 TTL。CNAME 为解析后的规范名，无别名时为空。 |
| IP 信息 | 专用/特殊地址在本地分类；公网地址发送 ipwho.is，返回大致归属地、ASN/运营商与时区。共享免费配额，结果缓存六小时。 |
| UA 解析 | 浏览器内 Bowser 规则，不上传 UA，不保证可识别被缩减或伪造的设备信息。 |
| URL 解析 | 浏览器 WHATWG URL，展示规范化组件与保留重复键的参数列表，不访问 URL。 |
| 在线 GET/POST | 服务器实际发送 HTTP/HTTPS 请求，支持自定义请求头和 POST 文本体，查看状态、响应头与正文；不跟随跳转、不访问非公网地址。 |

## 限制

- 文本 Base 编码最多 256 KiB；二次方复杂度的 Base36/58/62 最多 8 KiB。整数换算最多 10,000 位。
- JSON 1 MiB，SQL/正则测试文本 256 KiB；格式化 8 秒，正则 2 秒。正则最多展示 200 项匹配、每项 12 个捕获组，长内容会明确截断。
- 随机数每批 1–1000 个、范围最多 256 位，精度 0–12 位小数；密码每批最多 50 个、每个 1–256 字符；UUID 每批最多 1000 个。
- 图片上传 12 MiB，输入/输出 2400 万像素、单边 12000；AVIF 输出最多 800 万像素，结果最多 25 MiB，任务限时 25 秒。同一实例同时处理一项 FFmpeg 任务。
- HTTP 请求体 256 KiB，响应体 1 MiB，12 秒超时；二进制正文以 Base64 返回，不渲染上游 HTML。网络任务并发上限 8。

IP 服务文档：<https://ipwhois.io/documentation>。地理结果是网络地址的大致位置，不是个人精确位置。
